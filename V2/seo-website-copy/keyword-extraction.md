# Keyword Extraction & Research Helper

## Purpose
Quick reference for identifying and extracting SEO keywords from client information, competitor sites, or existing content.

## Keyword Extraction Process

### From Client Input
When client provides service/industry info, extract:

1. **Primary Service Keywords**
   - Main service offered
   - Industry-specific terms
   - Common variations

2. **Geographic Keywords**
   - Cities mentioned
   - Counties/regions
   - Neighborhoods
   - State

3. **Problem Keywords**
   - Pain points mentioned
   - Customer problems solved
   - Specific conditions addressed

4. **Differentiator Keywords**
   - Unique selling points
   - Speed indicators ("fast", "24/7", "same day")
   - Process benefits ("no fees", "as-is", "cash")

### From Competitor Sites (via web_fetch)
When analyzing competitor URL:

1. **Extract from Title Tag**
   - Primary keywords (usually front-loaded)
   - Geographic terms
   - Brand differentiators

2. **Extract from Headers (H1, H2)**
   - Service categories
   - Location variations
   - Key benefits

3. **Extract from Meta Description**
   - Call-to-action phrases
   - Urgency indicators
   - Value propositions

4. **Extract from "Areas Served" Section**
   - All city names
   - County names
   - Neighborhood lists

5. **Extract from Body Copy**
   - Repeated phrases (likely targeted keywords)
   - Problem statements
   - Solution terminology

### From Old Content (Replacement Projects)
When client provides existing text:

1. **Identify What Works**
   - Keywords already ranking
   - Natural-sounding phrases
   - Effective CTAs

2. **Identify What Needs Improvement**
   - Generic language
   - Missing location keywords
   - Weak calls-to-action
   - Outdated information

3. **Extract Core Elements to Preserve**
   - Brand voice/tone
   - Specific claims/guarantees
   - Unique value props
   - Contact information

## Quick Keyword Formulas

### Primary Keyword Construction
`[Service] + [City/Region]`
Examples:
- Water damage restoration Phoenix
- Sell house fast Pittsburgh
- Healthy homes realtor Scottsdale

### Long-Tail Variations
`[Modifier] + [Service] + [City]`
Examples:
- Emergency water damage restoration Phoenix
- Sell house fast for cash Pittsburgh
- Environmentally sensitive homes realtor Scottsdale

### Problem-Aware Keywords
`[Problem] + [Solution] + [City]`
Examples:
- Mold damage house buyers Pittsburgh
- Flood cleanup service Phoenix
- Toxic mold home inspection Scottsdale

### Near Me Variations
Always include:
- [Service] near me
- [Service] in [City]
- [Service] [City] [State]
- Best [Service] near me
- [Service provider] close to me

## Keyword Priority Matrix

### High Priority (Must Include)
- Primary service + primary city (H1)
- Service + county name (H2)
- "[Service] near me" variant (body copy)
- Top 3 neighborhoods/suburbs (Areas Served)

### Medium Priority (Should Include)
- Secondary cities in service area
- Related service variations
- Problem-solution phrases
- "Best [service]" variations

### Low Priority (Nice to Have)
- Tertiary locations
- Informational keywords
- Industry jargon
- Competitor brand names (carefully)

## Red Flags to Avoid

### Keyword Stuffing Signs
- Keyword used more than 3x in a single paragraph
- Unnatural phrasing to force keywords
- Repeated exact-match phrases
- Keyword-only paragraphs with no value

### Over-Optimization
- Every H2 has identical structure
- City name in every sentence
- Robotic, unnatural language
- Sacrificing readability for SEO

### Competitor Copying
- Identical phrasing from competitor sites
- Same keyword order/structure
- Copied testimonials or guarantees
- Matching service descriptions

## Search Intent by Keyword Type

### Transactional (Ready to Buy)
Keywords: "hire", "get", "buy", "contact", "call", "near me"
Content needs: CTA, form, phone number, pricing, process

### Commercial (Comparing Options)
Keywords: "best", "top", "vs", "reviews", "cost"
Content needs: Why us, testimonials, comparisons, guarantees

### Informational (Researching)
Keywords: "how to", "what is", "guide", "tips", "cost"
Content needs: Education, process explanation, FAQ

### Problem-Aware (Urgent Need)
Keywords: Problem descriptions, specific conditions, "help", "emergency"
Content needs: Empathy, solutions, urgency response, immediate action

## Competitive Keyword Gap Analysis

When analyzing competitor:
1. List their top 10 keywords (from H1, H2, title)
2. Identify locations they target (Areas Served)
3. Note missing services/keywords
4. Find underserved sub-markets
5. Identify better ways to describe their services

## Client Brief Keyword Extraction Template

Use this mental checklist when starting a project:

**Client Info Provided:**
- [ ] Primary service/industry
- [ ] Geographic area (city, county, state)
- [ ] Target audience/customer
- [ ] Key differentiators
- [ ] Problems solved
- [ ] Urgency level (emergency, fast, standard)
- [ ] Unique processes or guarantees

**Missing Info (Ask Client):**
- [ ] Specific neighborhoods to target
- [ ] Top 3 search terms they want to rank for
- [ ] Competitor sites to reference/outrank
- [ ] Service area boundaries
- [ ] Any existing keyword data (Analytics, GSC)
