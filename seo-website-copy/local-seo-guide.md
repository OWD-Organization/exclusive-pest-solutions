# Local SEO Optimization Guide

## Core Local SEO Principles

### Geographic Keyword Layering
Create a hierarchy of location keywords:
1. **State level** - "[Service] Arizona" (broad reach, high volume)
2. **Metro area** - "[Service] Phoenix Metro" (regional targeting)
3. **City level** - "[Service] Phoenix" (primary local)
4. **Neighborhood** - "[Service] Scottsdale" (hyper-local)
5. **County** - "[Service] Maricopa County" (administrative region)

### Keyword Formula Variations
For each location, create variations:
- [Service] + [City]
- [Service] + in + [City]
- [Service] + near + [City]
- [Service] + [City] + [State abbreviation]
- [City] + [Service]
- [Service] + near me (implied local)
- Best [Service] + [City]
- Top [Service] + [City]

## Keyword Research Process

### 1. Identify Core Service
Primary service offering (e.g., "water damage restoration", "sell house fast", "healthy homes realtor")

### 2. Generate Location Variations
List all:
- Counties served
- Major cities in each county
- Suburbs and neighborhoods
- Zip codes (for deep local targeting)

### 3. Intent-Based Keywords

**Transactional Intent** (highest value):
- "[Service] [City]"
- "Best [Service] [City]"
- "[Service provider type] [City]"
- "Hire [Service] [City]"

**Problem-Aware** (bottom funnel):
- "[Specific problem] [City]"
- "How to [solve problem] [City]"
- "[Service] for [specific condition]"
- "[Urgent modifier] [Service] [City]"

**Informational** (top funnel):
- "How does [Service] work"
- "What is [Service]"
- "[Service] cost [City]"
- "[Service] vs [Alternative]"

### 4. Competitor Keywords
Search for competitors and identify:
- Keywords they rank for
- Service pages they create
- Location pages they target
- Gap opportunities

## On-Page Optimization

### Title Tag Formula
**Homepage:** [Primary Keyword] | [Secondary Benefit] | [City/Region]
- Max 60 characters
- Example: "Sell House Fast Pittsburgh | Cash in 7 Days | No Fees"

**Service Pages:** [Service] in [City] | [Key Benefit] | [Brand]
- Example: "Water Damage Restoration Phoenix | 24/7 Emergency Service"

### Meta Description Formula
[Hook] + [Core Benefit] + [Differentiator] + [Local Proof] + [CTA]
- Max 155 characters
- Must include city name
- Example: "Need to sell your house fast in Pittsburgh? Get a fair cash offer in 24 hours from local buyers. No fees, no repairs, close in 7-14 days."

### Header Structure
**H1 (One per page):**
- Include primary keyword + city
- Front-load important terms
- Example: "Pittsburgh Water Damage Restoration Services"

**H2 (Multiple allowed):**
- Include secondary keywords
- Natural language variations
- Geographic variations
- Example: "24/7 Emergency Water Extraction in Allegheny County"

**H3 (Subcategories):**
- Specific neighborhoods/areas
- Service variations
- Problem-specific solutions

## Content Optimization Strategies

### Keyword Density
- Primary keyword: 1-2% density (natural, not forced)
- Appear in first 100 words
- Include in last paragraph
- Use in image alt text

### Semantic Keywords
Include related terms naturally:
- Industry jargon
- Problem descriptions
- Solution terminology
- Process steps
- Equipment/tools used

### Local Signals

**Strong Signals:**
- NAP (Name, Address, Phone) consistency
- Embedded Google Map
- Local phone number in area code
- County/city mentions in content
- Neighborhood-specific pages
- Local landmark references

**Supporting Signals:**
- Customer testimonials with locations
- Case studies by area
- Service area lists
- "Locally owned" messaging
- "Serving [area] since [year]"
- Local community involvement

## Content Structure for Local SEO

### Homepage Requirements
✓ Hero with [City] + [Service]
✓ 3+ mentions of primary location
✓ "Areas We Serve" section
✓ Local testimonials
✓ Embedded map or location mention
✓ Local phone prominently displayed
✓ 800-1,200 words minimum

### Location Pages Formula
Create dedicated pages for each major service area:

**URL Structure:** /[city-name]/ or /[service]-[city]/

**Page Elements:**
1. H1: "[Service] in [City]"
2. Unique 300+ words about that location
3. List of neighborhoods/zip codes served
4. Local statistics/facts
5. Location-specific testimonials
6. Embedded map
7. City-specific CTAs

### Service Pages Formula
**URL Structure:** /[service-name]/

**Page Elements:**
1. H1: "[Service] in [Primary City]"
2. Service overview (200 words)
3. H2 sections for service variations
4. "Serving these areas:" location list
5. Problem-solution framework
6. Local benefits/advantages
7. FAQ with location keywords

## Areas Served Section Strategy

### Structure
Organize geographically for maximum SEO value:

```
## Counties, Cities & Areas We Serve
[Subhead with "service area" or "buy box" or "coverage area"]

### [County Name] County
- [City 1]
- [City 2]
- [City 3]
- [Neighborhood 1]
- [Neighborhood 2]
```

### Best Practices
- Group by county first (helps with county-level searches)
- Include 6-10 locations per county
- Mix major cities with smaller suburbs
- Use official city names (not nicknames)
- Include zip codes for hyper-local targeting
- Link each city to dedicated location page (if exists)

### SEO Impact
Each location name becomes:
- Rankable keyword combination
- Internal linking opportunity
- Geographic signal to search engines
- Trust signal to users

## Search Intent Targeting

### Map Keywords to Content Sections

**"Near me" searches** → Hero + Areas Served
- Include "[City]" in hero headline
- Feature location prominently
- Show service area map/list

**"Best [Service] [City]"** → Why Us + Testimonials
- Emphasize unique value props
- Include ratings/reviews
- Show local expertise

**"[Service] cost [City]"** → Pricing/Transparency section
- Address cost concerns
- Show value proposition
- Offer free quotes

**"[Problem] [City]"** → Problem-Aware section
- List specific problems you solve
- Include empathetic language
- Target bottom-funnel searchers

## Schema Markup Recommendations

For maximum local SEO impact, implement:
- **LocalBusiness Schema** - NAP, hours, service area
- **Service Schema** - Each service offered
- **Review Schema** - Testimonials with ratings
- **FAQ Schema** - Common questions
- **BreadcrumbList Schema** - Site navigation

## Competitive Analysis

When analyzing a competitor site or creating copy:
1. Identify their primary keywords (check title tags)
2. Note their geographic targeting (which cities/counties)
3. Analyze their content structure
4. Find keyword gaps they're missing
5. Identify underserved locations
6. Look for better ways to address search intent

## Local Link Building

Build local relevance through:
- Local directory listings (Yelp, YP, etc.)
- Chamber of Commerce memberships
- Local business associations
- Community sponsorships
- Local news mentions
- Hyperlocal blog content
- Neighborhood guides
